# Linux 7.2 candidate delivery (offline qualification)

This branch is `codex/mipad2-7.2-integrated`. The existing `arch_linux` and
`codex/mipad2-6.14-integrated` branches are not changed. This is not an image
release or a hardware/Android-parity sign-off.

## Separate kernel identity and rollback

The 7.2 package base is **linux-latte-integrated-7-2**. It has independent module,
boot image and mkinitcpio preset paths. It must not replace the 6.14
`linux-latte-integrated` package or its boot files. Source builds accept only
6.14 or the requested 7.2.0 family; the latter uses explicit positive rN and
`-mipad2-integrated` configuration. They never select the build host CPU.

Kernel binary source: E7G/linux_latte@b3d6da61c786c2dced579a935cf4498605db107e,
retaining requested upstream 9928c7b8d00c500ee97903afa1cc76c1c36ab2bc.
Kernel release: 7.2.0-mipad2-integrated-r1. Full build and 32 kernel host tests pass.

The binary repacker uses real unprivileged makepkg. It validates the external
bundle/certificate SHA256 pins, every original payload hash, release banner,
module vermagic and all 31 detached CMS signatures. The initial 7.2 bundle has
no certificate-serial metadata; this does not skip actual CMS validation.
A separately generated wrong certificate is rejected by OpenSSL CMS.

## Matching userspace without breaking a 6.14 fallback

UCM pkgrel8 selects a complete `Left Amp Input`/`Right Amp Input` pair or the
legacy `Amp Input`/`Amp Input1` pair at load time. Partial or unknown layouts
fail before any mixer write, and both channels are routed before powering the
speaker path. Actual ALSA 1.2.15.3 and 1.2.16.1 parser/sequence tests pass against
explicit synthetic controls. These are not physical DAPM, PCM or acoustic tests.

## Image and CI gates

The image builder consumes an explicitly supplied `KERNEL_PACKAGE` with its
mandatory `KERNEL_PACKAGE_SHA256`; `KERNEL_PKGBASE`, if supplied, must agree with
the package metadata. Family/base mismatches fail before writing a boot image.
118 host tests cover old behavior plus the separate 7.2 identity, coexistence,
installer failure preservation, source-family/revision gating and unsafe pins.

The workflow remains **manual dispatch only**, requiring a published full source
commit. Its source reference now identifies the 7.2 integration branch. It has
not been dispatched or claimed green. The support manifest retains its legacy
shared `usr/share/doc/linux-latte-cachyos/support-payload.json` location, while
the source-commit and kernel-release provenance use the actual package base.

## Still required on the actual tablet

Verify console/recovery/no-idle/thermal prerequisites, then keep the saved 6.14
default and test an isolated one-shot entry. Qualify cold boot, both cameras,
photo/recording cadence, speaker/headset/mics, orientation, charging, Wi-Fi,
USB roles, suspend/resume and actual S0I3/power behavior. The r27 failed-reset
DMA safety and intermittent S0I3 issue are not solved by packaging or host tests.
